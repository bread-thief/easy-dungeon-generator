# Easy Dungeon Generator

[![Unity Version](https://img.shields.io/badge/Unity-2021.3+-blue.svg)]()
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Professional procedural dungeon generator for Unity with 2D/3D support.

## ✨ Features

- 🚪Connector-based room placement
- 🎮 2D and 3D project support
- 🛠️ Performance optimized with frame-based generation
- ⚙️ Visual debugging tools
- 🧱 Multiple regeneration attempts
- 🎨 Customizable room prefabs

## 📦 Installation

### Via Package Manager (UPM)
1. Open `Window > Package Manager`
2. Click `+` → `Add package from git URL`
3. Copy and paste this URL:

```
https://github.com/bread-thief/easy-dungeon-generator.git
```

### Manual
Clone or download this repository and copy the contents to your Unity project's `Assets/` folder.

### Alternative: Add to manifest.json
Add this to your `Packages/manifest.json`:
```json
"com.bread-thief.hierarchy-selector": "https://github.com/bread-thief/easy-dungeon-generator.git"
```

## 🏳️ Quick Start
1. Add EasyDungeonGenerator component to GameObject
2. Assign start room and room prefabs
3. Click "Generate Dungeon" in Inspector

## ⚙️ Requirements

- Unity 2021.3 LTS or higher
- .NET 4.x / .NET Standard 2.1
